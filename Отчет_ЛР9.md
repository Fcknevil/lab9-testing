## 1. Цель и объект тестирования

Цель — настроить автоматический запуск Python-тестов при push и создании pull request в GitHub.

Объект — небольшой проект с классом `Calculator` и pytest-тестами сложения, деления и исключения при делении на ноль.

## 2. Workflow

Файл `.github/workflows/run-tests.yml` выполняет следующие шаги:

1. запускается на Ubuntu;
2. получает код репозитория через `actions/checkout`;
3. устанавливает Python 3.12 через `actions/setup-python`;
4. включает кэш pip;
5. устанавливает зависимости из `requirements.txt`;
6. запускает `python -m pytest -v`.

Workflow срабатывает на событиях `push` и `pull_request`.

## 4. Публикация в GitHub

После создания репозитория выполнить из папки `lab9`:

```bash
git init
git add .
git commit -m "Add automated tests and CI workflow"
git branch -M main
git remote add origin https://github.com/<username>/<repository>.git
git push -u origin main
```

Затем открыть вкладку **Actions** в GitHub и показать успешный workflow с зелёной галочкой.

## 5. Результат

Подготовлены тестовый Python-проект и YAML-конфигурация GitHub Actions. Локальная проверка тестов выполняется без внешних сервисов. Публикация и фактический запуск workflow требуют URL репозитория и учётных данных GitHub, поэтому push из этой лабораторной папки не выполнялся.
